# Host deadlines and meet pricing

Admin lists and details display the host entry deadline in Pacific time.
Priority: host-confirmed extension, announcement deadline, PNS deadline, legacy
effective deadline. Unpublished meets with a deadline before today enter Past
archive. Unknown deadlines stay in review. Published/submitted meets retain their
operational workflow until the meet ends. Families see only the Prime deadline
in the application; the linked original announcement remains available.

PDF extraction reads explicitly labelled entry deadlines and saves the entry-fee
section for admin review. It does not infer event groups from prose. Existing
saved meets receive this information on the next PNS scan. Published source
changes still require acceptance.

Pricing supports the existing surcharge and default event fee, per-event price
groups, an inclusive flat swimmer fee, and additional charges/credits per swimmer,
selected date, selected session, or percentage of the base fee. Percentages use
surcharge + event fees (or flat fee), without compounding other additional charges.
Charges can target event numbers and specific swimmers. Negative charges are
credits; totals never go below zero. Explicit event overrides may be zero.
Overrides take priority over Event File prices, then the default fee.
Flat pricing includes event fees. Daily pricing requires identifiable session
dates and rejects ambiguous dates. Team/relay fees are not automatically divided
among swimmers: staff must confirm and enter any per-swimmer allocations.

For BBST November 2026, verify the original announcement and imported file:
$25 surcharge; $4.50 timed finals (event 1 and events 16–23, 36–42);
$7 prelims/finals (events 2–15, 24–35). Count a prelim/final event once.
A swimmer entering event 1 plus three prelim/final events is estimated at $50.50.
The announcement entry deadline is October 27, 2026, so an unpublished meet is
archived on October 28 unless the host confirms an extension.

Family estimates are explicitly provisional; final fees are determined by the
host and confirmed by Prime. Source scans preserve admin-authored pricing rules.
